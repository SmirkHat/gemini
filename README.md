# Gemini Watermark

Experimentální nástroj pro studium AI vodoznaků. Přetáhni obrázek a stáhni ho s vodoznakem  -  vše běží lokálně v prohlížeči.

## O projektu

Tento projekt zkoumá, jak fungují vodoznaky v AI-generovaných obrázcích. Nejde o oficiální nástroj žádné AI platformy  -  je to nezávislý edukativní výzkum.

## Stack

- [TanStack Start](https://tanstack.com/start) (React 19, SSR, file-based routing)
- [Tailwind CSS](https://tailwindcss.com)
- [shadcn/ui](https://ui.shadcn.com) + [Lucide](https://lucide.dev) ikony
- [Geist](https://vercel.com/font) font (self-hosted přes Fontsource)

## Spuštění

```bash
pnpm install
pnpm dev        # http://localhost:3003
pnpm build      # produkční build
pnpm typecheck  # kontrola typů
```
